# PoketPals AI — website

Marketing site for [PoketPals AI](https://github.com/reehazshrestha/PoketPals-AI), a private on-device AI companion for Android.

Built with Vite, React, TypeScript, Tailwind CSS v4 and Lucide icons. The page is a single responsive landing page: hero with an app mockup, three features, a voice section, a privacy section and a download section.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
npm run preview  # serve the production build
```

## Assets

- App logo: `src/assets/poketpals.webp`, taken from the PoketPals AI app
  (`src/assets/poketpals-icon.png` in the app repository).
- Fonts: Outfit and Work Sans, self-hosted in `src/assets/fonts/`. Both are
  licensed under the SIL Open Font License; see `src/assets/fonts/OFL.txt`.
- Icons: [Lucide](https://lucide.dev), ISC license.
- The brand palette (peach, sage, sky, butter, ink) is derived from the app's
  logo and theme tokens.
- Design-system notes from the UI/UX pass live in `design-system/poketpals-ai/`.
